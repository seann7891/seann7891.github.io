## 2. P0：畫面與物理或正文矛盾（必修）

### P0-1　1-6 第 4 步「窄縫後為什麼展開」：畫面縫寬與標示的 a/λ 不符，展開角也與 4-3 公式不一致

- 位置：`simulations.mjs:222`（`kind==='diffraction'&&settings.water`），`simulations.mjs:6`（`diffractionHalfAngle`）。
- 問題 1：入射波前間距（λ）畫成 65 px，縫寬卻是 `max(18, 18×a/λ)` px，所以畫面上的縫寬波長比與標示值不同：

  | 標示 a/λ | 0.5 | 1 | 2 | 3 | 5 |
  |---|---|---|---|---|---|
  | 畫面實際 a/λ | 0.28 | 0.28 | 0.55 | 0.83 | 1.38 |

  學生在這一步要學的正是「縫寬和波長的比值」，畫面比例卻全錯。標示 a/λ = 5 時，畫出來的縫仍和波長差不多寬。
- 問題 2：展開半角用 `0.8/(a/λ)` 弧度（上限 1.25），和 4-3 教的 `sin θ = λ/a` 不一致。a/λ = 2 時模型給 22.9°，第一暗紋實際在 30°；a/λ = 1 時模型給 45.8°，實際已展開到 90°。
- 修正：
  1. 取 `λpx = 40`，令 `gap = (a/λ) × λpx`。a/λ = 5 時縫寬 200 px，仍在牆面 70–430 px 範圍內。入射波前間距同步改為 `λpx`。
  2. 半角改用 `Math.asin(Math.min(1, 1/ratio))`，ratio ≤ 1 時畫到 ±90°。讀數補一句「以第一暗紋方向 sin θ = λ/a 作為展開範圍示意」，與 4-3 銜接。
  3. （建議）a/λ 大時，出射波前中央畫成寬度 a 的平直段，只在兩側畫圓弧，避免讓學生以為寬縫後的波前也全是圓弧。
  4. 新增測試：畫面縫寬 ÷ 畫面波前間距 = 標示 a/λ。

### P0-2　3-1 第 3 步「池底為何看起來比較淺」：虛線不是實線的真實反向延長，也無法呈現正文第二段

- 位置：`simulations.mjs:195`。正文 `course.json` 3-1 第 3 步第二段寫「大角度時各光線的延長線不一定交於同一點」。
- 問題：程式把每條虛線都畫到近軸像點 `depth/n`，不是沿著折射光反向延長。虛線和實線因此不共線，最大偏差 5.8 px（真深 1 m、n = 1.6、dx = 30 px）。所有虛線又被強制交在同一點，正文第二段描述的現象在畫面上永遠看不到，任務「比較實線折射光與虛線延長線」反而可能讓學生建立錯誤印象。
- 修正：
  1. 每條虛線沿出射方向的反方向延長，與法線交於 `y = dx / tan(out)`。
  2. 另用一個點標「近軸像（真深/n）」。
  3. 新增「觀察斜度」控制（光線離法線的水平距離 dx，例如 10–120 px）。大角度時，學生可以看到各延長線交點分散、整體變得更淺。
  4. 新增測試：虛線方向與實線方向共線。

### P0-3　2-3 第 2 步「用兩次共鳴避開管口誤差」：畫面沒有共鳴反應、答案直接顯示，也沒有管口修正

- 位置：`simulations.mjs:170-176`；任務在 `course.json:834`。
- 問題：
  1. 任務要學生「拖空氣柱長度，找相鄰兩個反應峰」，但畫面粒子振幅固定 4 px（`4*Math.sin(k*x)*…`），不隨共鳴程度改變。反應大小只出現在讀數文字 `amp`，畫面上沒有「峰」可找。
  2. 右側「預期共鳴長度」刻度一開始就顯示正確答案，學生不必操作就能讀到答案。
  3. 標題與正文的重點是用 `Lₘ + e` 相減消去管口修正 e，模擬卻寫「忽略管口修正」（e = 0），無法展示這個核心想法。
- 修正：
  1. 粒子振幅乘上正規化反應 `amp/ampMax`。旁邊加一條直立的反應量條，或畫「反應—L」曲線並以游標標出目前的 L。
  2. 預期刻度改由「顯示理論位置」按鈕開啟，預設隱藏。
  3. 新增「管口修正 e」選項（例如 0 或 0.6r，r 取 1.5 cm）。共鳴條件改為 `L + e = (2m−1)λ/4`。讀數記下學生找到的 L₁、L₂ 及 L₂ − L₁，讓學生親眼看到差值仍是 λ/2。

### P0-4　1-6 第 1 步「水波槽與反射」：正文指向不存在的三維波面

- 位置：`course.json:500`「先用三維波面辨識波峰」，概念標籤「波面高度」。
- 問題：前一輪改版已把水波反射改成俯視平面圖，畫面沒有三維波面，也沒有波面高度。
- 修正（二擇一）：
  - 只改文字：把第二段開頭改成「俯視圖中的短線代表波峰波前。」，概念「波面高度」改為「波前」或「入射角」。
  - 或加回一個可切換的「側視水面高度」小圖，作為第一段「投影亮暗≠水面高度」的證據。
- 順便清除：`course.json:519` 的 `"optionKeys": ["fixed","free"]` 是從 1-3 複製來的殘留，對水波沒有作用。

### P1-2　2-1、2-2 聲波粒子列與下方曲線水平位置不對齊

- 位置：`simulations.mjs:158-160`。粒子用 3D 投影（yaw 15° 時 x ≈ 180–720 px），曲線用 70–830 px。
- 問題：2-1 第 2 步要學生「找密集區和位移為零的點」，必須把粒子位置對到曲線位置，但兩者的 x 座標系統不同，看到的對應點是錯的。2-2 對照管端節腹時也有同樣問題。
- 修正：曲線 x 範圍改成粒子在 yaw = 0 時的投影範圍（`450 ± 280`）；這兩步的預設 yaw 設為 0；從黃點畫一條垂直對位線到曲線。2-1 第 2 步另標出「密部中心」「疏部中心」。

### P1-3　1-1 第 2 步沒有畫出波源

- 任務是「觀察波源行為」（`course.json:76`），但畫面沒有手或振盪源，脈衝一開始就出現在 x = 1 m。前一輪報告承諾的「波源行為以簡單符號連到波形」和「再發送一次」都沒有實作。
- 修正：在 x = 0 畫一個上下移動的端點，標示「手／波源」。脈衝模式下，波源只在 t ≈ 0–0.3 s 抬起再放回一次；週期模式下持續振動。波形從 x = 0 生成，並加上「再發送一次」按鈕。

### P1-4　1-1 第 1、3 步，1-2 第 2 步：紫色「波峰」標記

- 時間軸是 0–8 s，但波峰標記約在 t > 3.5–3.9 s 時就移出畫面（`simulations.mjs:75` 的 `crest` 沒有取餘數），之後一半時間都看不到。修正：`xCrest = ((f·t + 0.25)·λ) mod λ`，再取畫面內第一個波峰。
- 縱波模式仍標「● 波峰」，對縱波沒有物理意義。修正：縱波模式隱藏這個標記，改標「密部中心」（ξ = 0 且 ∂ξ/∂x < 0 處）。這也是前一輪報告承諾「縱波顯示稀疏／密集」的未完成項。
- 備註：目前縱波最大應變 A·k = 0.57，是安全的。若之後開放頻率到 2 Hz，A·k 會變成 1.14，相鄰粒子將交錯而不符物理。屆時振幅要改成 `A ∝ λ`。

### P1-5　3-3 透鏡：沒有主光線，與「逐條追光線」及講義作圖法不一致

- 位置：`simulations.mjs:206-213`。單元目標是「逐條追光線」，講義 3-3 也以「作圖方法」（三條主光線）為核心。
- 問題：程式畫的是一條平行光線，加上兩條在 z = ±0.55 的斜交光線。成像在數學上正確，但在預設俯角下，斜交光線投影後不像「通過鏡心」也不像「通過焦點」，學生找不到正文提到的「通過鏡心的近軸光線近似不偏折」。3-3 第 1 步問凹透鏡虛焦點，虛線卻只延伸到像點、碰不到 F，模擬裡也沒有平行光束。
- 修正：
  1. 預設在子午面（z = 0）畫三條主光線：平行→過 F'、過鏡心不偏折、過 F→平行。用編號和顏色區分。三維光束改為進階選項。
  2. 3-3 第 1 步新增「平行光束」模式：5 條平行入射光。凸透鏡會聚到 F'；凹透鏡的發散光反向延長匯於 F。

### P1-6　3-3 第 4 步：概念「光屏位置、調焦、近視矯正、遠視矯正」沒有畫面

- 修正（擇一）：
  - 在透鏡模擬加一個可拖動的「光屏」，讀數顯示「屏位置 − q」，為 0 時畫面變清晰。另加「眼睛模式」：固定視網膜距離，切換無/凹/凸矯正鏡。
  - 或縮減概念為「光屏位置、放大鏡」，矯正視力改成純文字補充。

### P1-7　4-3 第 4 步：概念「結構色、薄膜干涉」借用雙縫模擬

- 現況：任務自承「只是多路疊加的類比」，但檢核題問的是肥皂膜。
- 修正：新增一個簡單的 `thinFilm` 模擬，包含膜厚 t、折射率 n、反射半波相位開關，以 `2nt` 計算各色反射強度，顯示色帶隨膜厚變化。或把本步的概念和題目改成與雙縫一致的內容。

### P1-8　4-3 第 2 步：任務「比較旁峰亮度」與正規化強度衝突

- 位置：`course.json:1309`。強度每次正規化到 I₀，旁峰相對亮度恆為約 4.7%，與 a 無關。學生會看到「沒變」，卻得不到解釋。

### P1-9　3-2 第 1 步：「臨界狀態」標示永遠不會出現

## 4. P2：呈現、措辭與程式整潔
